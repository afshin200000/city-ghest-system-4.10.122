# آموزش تنظیمات پیشرفته — فرم‌ساز و تب‌ها

## تب‌های تنظیمات (شهر قسط → تنظیمات)

| تب | کاربرد |
|----|--------|
| عمومی | نام مجموعه، لوگو، تقویم، رنگ‌ها |
| پیامک | ارائه‌دهنده، API Key، فرستنده |
| امضا دیجیتال | ارائه‌دهنده امضا |
| مخاطبین | افزودن/حذف انواع مخاطب + برچسب فارسی |
| استعلام API | کدملی، پستی، موبایل، شبا، اعتبار + ارائه‌دهندگان |
| درگاه پرداخت | زرین‌پال، بانک‌ها، … |
| صدا | صدای موفقیت و بلندی |

در **هر تب** دکمه **ذخیره همه تنظیمات** را بزنید.

## فرم‌ساز داینامیک

1. **قالب آماده:** از لیست ۵۰ قالب یکی را انتخاب و «اعمال قالب» کنید.
2. **مراحل:** برای هر مرحله نام، آیکن، تعداد ستون، فایل آموزشی.
3. **پیش‌نمایش:** ستون‌ها را عوض کنید → اعمال / به همه → ذخیره مراحل.
4. **عرض فیلد:** دکمه‌های ۲۵/۳۳/۵۰/۱۰۰٪ یا کشیدن لبه فیلد → ذخیره چیدمان.
5. **ظاهر:** رنگ، فونت، شیشه‌ای، سایه → ذخیره ظاهر فرم (باید روی پیش‌نمایش دیده شود).

## پایداری تنظیمات

- تنظیمات سایت → `cgs_settings` در دیتابیس
- ظاهر فرم → `cgs_form_styles`
- مراحل → `cgs_step_meta_{type}`
- فیلدها → جدول `wp_cgs_form_fields`

اگر بعد از ذخیره چیزی برگشت، کش مرورگر و افزونه کش را خالی کنید و دوباره **ذخیره** را از همان تب بزنید.
