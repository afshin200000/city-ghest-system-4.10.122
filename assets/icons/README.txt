آیکن‌های افزونه شهر قسط
========================
static/     — آیکن‌های SVG ثابت (user, phone, bank, ...)
animated/   — آیکن‌های SVG متحرک (spinner, thumbs-up, ...)
fontawesome/cgs-icons.css — کلاس‌های CSS برای استفاده آسان

مثال:
<span class="cgs-icon cgs-icon-user"></span>
<span class="cgs-icon cgs-icon-lg cgs-icon-spinner"></span>
