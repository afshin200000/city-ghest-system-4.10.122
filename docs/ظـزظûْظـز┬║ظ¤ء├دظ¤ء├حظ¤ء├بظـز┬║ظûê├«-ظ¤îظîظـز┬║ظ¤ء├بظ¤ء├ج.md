# راهنمای کامل افزونه شهر قسط (نسخه 3.3.0)

## ۱. نصب
1. فایل ZIP را از افزونه‌ها → افزودن → بارگذاری نصب کنید.
2. افزونه را **فعال** کنید.
3. کش مرورگر: Ctrl+Shift+R
4. منوی **شهر قسط** در پیشخوان ظاهر می‌شود.

## ۲. تنظیمات (۱۲ تب)
| تب | کاربرد |
|----|--------|
| عمومی و برند | نام، لوگو، حقیقی/حقوقی |
| پیامک | کاوه‌نگار و … |
| امضا دیجیتال | ارائه‌دهنده امضا |
| تضمین | چک و سفته |
| مخاطبین | انواع فرم |
| استعلام و API | شاهکار و خودکارسازی |
| درگاه پرداخت | زرین‌پال، آیدی‌پی، بانک‌ها |
| صدا | افکت موفقیت |
| ظاهر و فونت | رنگ و فونت B |
| تقویم شمسی | جلالی |
| CRM | اتصال خارجی |
| سیستم و دیتابیس | بهینه‌سازی و نمودار |

هر تب دکمه **ذخیره** دارد.

## ۳. فرم‌ساز داینامیک
- تب نوع مخاطب را انتخاب کنید.
- قالب آماده را اعمال کنید یا فیلد بسازید.
- **منطق شرطی:** در validation فیلد به‌صورت JSON:
```json
"conditions": {
  "enabled": true,
  "action": "show",
  "logic": "and",
  "rules": [
    { "field": "person_type", "op": "equals", "value": "legal" }
  ]
}
```
عملگرها: `equals`, `not_equals`, `contains`, `empty`, `not_empty`

## ۴. درگاه پرداخت
1. تنظیمات → درگاه پرداخت
2. درگاه را انتخاب و Merchant/API Key را وارد کنید.
3. حالت آزمایشی (Sandbox) را برای تست روشن بگذارید.
4. Callback به‌صورت خودکار توسط افزونه مدیریت می‌شود.
5. لاگ دیباگ در option به نام `cgs_payment_debug_log` ذخیره می‌شود.

**رفع خطای رایج درگاه**
| علامت | راهکار |
|--------|--------|
| درگاه انتخاب نشده | gateway را از none خارج کنید |
| خطای merchant | کلید را بدون فاصله از پنل درگاه کپی کنید |
| verify ناموفق | callback URL را در پنل درگاه با آدرس سایت یکی کنید |
| مبلغ صفر | amount را به ریال و عدد صحیح بفرستید |

## ۵. پایش عملکرد
منوی پایش کوئری‌ها آمار را نشان می‌دهد و **مشاور هوشمند** به فارسی:
- علت احتمالی کندی
- راهکار دقیق (کش، ایندکس، SAVEQUERIES)
