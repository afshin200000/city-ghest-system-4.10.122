سیستم جامع جذب نماینده، فروشنده، بازاریاب، سرمایه‌گذار و متقاضی اعتبار برای شهر قسط.

== Description ==

* فرم‌های چندمرحله‌ای داینامیک با نوار پیشرفت
* فرم‌ساز با قابلیت درگ‌اند‌دراپ
* داشبورد اختصاصی متقاضی (بدون ردپای وردپرس)
* سیستم چت داخلی
* پیامک قابل تنظیم (کاوه نگار و ...)
* پشتیبانی تاریخ هجری شمسی و میلادی
* سازگار با Elementor Pro و Jupiter X

== Installation ==

1. پوشه city-ghest-system را در /wp-content/plugins/ آپلود کنید.
2. افزونه را از پنل افزونه‌ها فعال کنید.
3. صفحات مورد نیاز به صورت خودکار ساخته می‌شوند.
4. از منوی «شهر قسط» تنظیمات را انجام دهید.
